# 8条B站瓦圈用语 / Eight Bilibili VALORANT expressions

新增KSKBL、ZDJD、砌歪墙等社区语境说明。来源与日期逐条保留，不作为实时开播、人物指控、热榜或真实赛果。将vct-bili-memes.md导入既有的公共游戏知识库并重建索引；不要导入私人记忆集合。将entries.json按id合并到public-knowledge-entries.json，保留已有和自定义条目。原106条游戏、52条常用梗加本次8条，标准公共目录共166条。修改JSON不等于自动更新原生向量索引，两个入口需分别同步。

Adds community-context explanations for KSKBL, ZDJD, 砌歪墙 and related expressions. Per-entry sources and dates are retained; these are not live-stream status, personal accusations, popularity rankings or verified results. Import vct-bili-memes.md into an existing public game knowledge collection and rebuild its index, never into private memory. Merge entries.json into public-knowledge-entries.json by id, preserving existing and custom entries. The standard public catalog totals166 entries:106 game entries,52 general expressions and these8 additions. Editing JSON does not automatically rebuild the native vector index; synchronize both separately.
