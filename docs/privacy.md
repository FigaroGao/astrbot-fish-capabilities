# 隐私、身份与可分享范围

[English](privacy.en.md)

仓库作者不是机器人主人的身份。新部署者必须在本机填写自己的 `owners`、AstrBot管理员、平台ID和会话范围；B站主人UID与机器人登录账号也分别核验。默认不绑定任何原设备身份。

不要导入其他人的人格主体、聊天历史、滚动摘要、向量库、数据库、信箱、B站Cookie、QQ登录目录、恢复器密码文件或待审草稿。即使其中没有API Key，记忆也可能让模型把别人的身份和经历当成自己的。

发现“主人认错了”时，逐项检查：当前人格提示词、全局提示词、会话摘要、召回条目及metadata、工具注入的身份字段、共享缓存与第三方插件。模型的一句自述不能证明某个网页含有该事实。保留来源和时间，先隔离有问题的条目，再纠正原条目和摘要；只追加一句否认不能消除旧召回。

主人私聊、群公共范围与群成员范围必须在检索后按metadata核对，不能仅靠提示词中的标签隔离。跨窗口时间线默认为主人私聊资料，公开评论仍需独立审核；审核不能代替数据权限边界。

WebUI只在本机访问，远程使用已认证隧道或私有网络。不要把Key、密码、Cookie、Token贴进聊天、命令行参数、截图或Git。将本地备份放在仓库外。第三方API会接收对应请求内容，应按自己的隐私需求启用。

本次检查当前文件和可见Git历史未找到用户所指的私人主人昵称；这不是对所有外部副本或第三方机器人记忆的证明。若以后确认敏感内容确实进过Git历史，应撤销相关凭据，再评估历史清理；不能仅在新提交删除就声称历史已清除。
