# 2026-10-30—31 更新、迁移与验证

[中文](update-20261031.md) | [English — 完整翻译](update-20261031.en.md)

本次以10月29日远端版本为基础补齐之后的通用实现。所有分享能力开关仍默认关闭；不包含维护者的账号、课表、提示词主体、聊天、记忆、音色绑定或凭据。桌面陪伴程序在独立仓库：[Xiaojing-Screenmate](https://github.com/FigaroGao/Xiaojing-Screenmate)。

## 功能变更

| 功能 | 本次变化与边界 |
| --- | --- |
| 普通B站视频 | 策略版本10：预览分类后，获取正常播放权限下的源视频，用低分辨率场景变化分配概览；模型再选实际编号、裁剪或时间窗，重新从同一源视频取画面细看。最多两段30秒窗口、6张细看图；不是逐帧完整观看，不包含原声理解。 |
| 聊天／图片视频 | 保留原逐页路径。超过发现页面预算时覆盖已解码的整段时间线，标记预算受限，不再把开头几十秒当整段；不保证极短闪图、模糊文字全读到。 |
| B站提及与动态回复 | 主人@通知回复其实际原评论，以原话和视频为依据；通知没有原评论ID时停止，避免另发无关根评论。动态楼层定位、回复状态和评论目标校验补修；保留原权限与审核。 |
| 上下文费用 | 已完成历史轮次剔除积压推理字段，当前工具轮次保留协议所需内容；已完成轮次的旧图片／音视频换成标记，文字和当前正在处理的媒体保留。请求压缩不等于删除原始数据库或文件，也不是固定费用降幅承诺。 |
| 日常陪伴 | 增加日常相处风格补充，鼓励有依据的偏好和自然交流，不句句建议、总结或自我介绍。保留诚实的能力边界，不虚构身体经历，不将视频二创人物经历记成自己。不分发私人提示词主体。 |
| 慢任务先回应 | 主人私聊的刷站、视频、天气、Canvas和商店等较慢交互，授权后先发一句短回应，再执行；同轮去重，后台定时不额外发送任务回执。短回应不代表任务成功。 |
| 已确认Lecture课表 | `fish_course_progress(operation="schedule", query="周一")` 可查本机已确认的常规Lecture计划；课程简称沿用课程绑定。缺少私有课表时不猜时间，不推断用户此刻在上课，也不自动创建提醒。 |
| 掌瓦只读稳定性 | 对已确认超时的只读请求有限重试；同步失败有缓存时明确返回旧数据和刷新失败，登录态失效仍需本人验证。补齐读取异常处理，不承诺所有账号字段始终可取。 |
| Vocu TTS | 增加可选适配器和本机隐藏密钥输入工具，合成结果转为16kHz单声道PCM供原QQ语音链路使用。不自动重试不确定的付费请求，不上传用户音色ID或Key。 |

## 视频升级

继续使用原 `bili_visual_enabled`、`bili_storyboard_enabled`、`bili_gallery_scan_enabled`；没有新增默认开启的账号权限。安装环境需要ffmpeg；源文件最多96MiB、时长最多10分钟，临时源文件结束或取消后清理。版本10使旧视觉阅读缓存失效，之后沿用现有缓存。

原视频仅按每秒2帧、64×36的画面做变化扫描，概览保留首尾和时间范围；源图细看最长边1600且不放大低清源。广告仍按已见端点、明确商业推广依据与高置信度处理，不因品牌露出就删。源不可用时标记`scene_fallback`并退回预览。普通路径最多三次视觉调用：既有分类／角色参考、新概览选择、最终理解；没有安装DSH、额外常驻模型或本地ASR，也不承诺参考项目的384 token计费。

返回`scene_overview_zoom`、场景区间、选段和实际帧清单。下载过源文件不等于完整看过／听过。完整技术说明见[场景概览与细看](bili-scene-v10.md)。

## 本机配置与升级

升级前备份自己的源码、配置与数据，只替换程序文件并重载能力插件；不要用默认关闭的示例覆盖运行配置。通常不需重启NapCat。本次没有改变评论预算、定时任务或主人授权范围。

课表文件放在插件私有数据目录的`owner-lecture-schedule.private.json`，由本人核对填写；示例结构见[私有课表示例](../examples/lecture-schedule.example.json)。它仅供主人私聊查询，不上传GitHub。Canvas绑定与课程进度原有功能不变。

Vocu先安装ffmpeg，复制[预设结构](../examples/vocu-setup.example.json)到同一私有目录的`vocu-setup.private.json`，填写自己有权使用的音色ID及语速。运行 `python tools/vocu_login.py` 隐藏输入自己的Key，工具保存本机凭据并选择Vocu；随后手动重载插件。电脑部署可设置`ASTRBOT_ROOT`指向安装目录。配置`tts_provider`默认仍是`sambert`，`tts_enabled`默认关闭。此配置步骤不调用付费合成；实际Vocu合成与QQ发送仍需本人短句验证。

## 验证

开发源完整回归659项通过，最终分享目录完整回归660项通过；均有一条既有audioop弃用警告。新视频专项覆盖普通／聊天分流、按时间选段、非法编号／窗口、广告排除、源尺寸、真实ffmpeg合成视频与清理。既有提及测试夹具补齐当前接口的暂停状态与原评论ID，没有放宽生产校验。

参考平板的实际Ubuntu环境通过合成视频完整链路：概览6张、细看4张、480×320源的下半区裁剪为480×160、临时目录清理成功。现场探针确认策略10、扫描器与ffmpeg可用，QQ及OneBot正常，临时探针已卸载，没有重启NapCat。该测试使用固定模型输出，没有真实B站源下载、真实视觉模型调用或公开发言；因此不证明真实站点成功率或模型选段准确率。其他用户的账号、源清晰度、网络与设备性能需要自行验证。
