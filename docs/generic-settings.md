# 通用部署设置

公开包不预设使用者的城市或学校。安装后按自己的环境配置；示例不是作者的个人运行配置。

## 时间与天气

```json
{
  "local_timezone": "UTC+08:00",
  "weather_default_city": "",
  "weather_default_country": ""
}
```

- `local_timezone` 支持 `UTC`、`UTC±HH:MM` 和 IANA 时区名称，例如 `Europe/Paris`。默认保持 UTC+08:00，避免旧安装升级后任务整体移时；支持夏令时的地区请用 IANA 名称。
- 时间表、主动活动窗口、群聊日预算、动态日预算、夜间回顾、本地用量统计和语音本地月预算采用此设置。识图供应商的峰谷计费窗口仍按其既有 UTC+08:00 规则计算，独立于使用者时区；它不是使用者所在地。
- 修改时区前先备份并列出已有任务；修改后重载插件、逐项检查下次执行时间。无时区的 `at:` 时间与 cron 按配置时区解释；带明确偏移的 `at:` 保持原绝对时刻。不要为了换时区重复创建任务。
- 天气城市默认为空，需自行填写或在查询时明确指定；国家/地区代码可留空，不按国家筛选。全部城市通过地名查询服务解析，同名地点需要确认，不按 IP 或学校推断所在地。
- 已有本机城市配置、Canvas 绑定、课表和记忆不会由公开包覆盖。当地法规、供应商服务范围与账号权限仍由对应服务决定。

## Canvas 学校绑定

使用[本机绑定工具](../tools/canvas_login.py)时，先输入学校 Canvas 的 HTTPS 根地址，例如 `https://canvas.example.edu`，再隐藏输入访问令牌。此示例域名不能用于真实登录。已有绑定更新令牌时可回车沿用本机保存的地址。

地址和令牌成对存于本机 `canvas.credentials.json`，不进入模型参数或公开示例。令牌只发送到该地址；禁止重定向、非 HTTPS、带用户名密码、非根路径或查询参数的地址。工具仅开放原有课程、作业和公告 GET 接口，不提供提交作业、发消息或修改成绩操作。学校未开放个人令牌或相应 API 时不可使用；不保证每个学校实例都兼容。

公开源码、文档和示例中的学校名称与城市指向已通用化。本次更新不改写 Git 历史；旧提交仍保留当时的文件版本。
