# 有限行为调节与只读自检

开启 `self_regulation_enabled` 后，小鲸可以通过原有 Agent 工具和自主活动选择，调节下表中的偏好。它们保存在独立的本机行为数据库，不编辑插件源码、AstrBot配置、原人格或云端模型权重。

| 允许的键 | 可选值 | 实际作用 |
| --- | --- | --- |
| `reply_style` | natural / brief / thoughtful | 附加预先写好的表达引导；普通闲聊长短可变，数据、解释、代码准确性优先 |
| `tone` | gentle / calm / playful | 温和、平和或适当俏皮，不强制口头禅、不编造经历 |
| `video_curiosity` | balanced / focused / explore | 在已有候选中更均衡、聚焦或探索；不改搜索权限、阅读上限和费用预算 |
| `meme_preference` | balanced / restrained / expressive | 调整考虑表情的倾向；不改变图库批准、冷却和发送上限 |
| `autonomy_interval_seconds` | 600 / 900 / 1200 / 1800 / 3600 | 自主活动一轮完成后再判断的间隔；最短仍10分钟，不改睡眠时段、后台轮询或固定时间表 |
| `group_initiative` | normal / quiet | 在已接入统一意图的群聊路径中，normal沿用原规则；quiet阻止普通主动接话，不阻止明确点名路径，也不能绕过主人强制静音 |

前四项是生成前的偏好引导，不是硬性保证每条文风；后两项实际接入自主循环和群聊程序判断。稳定身份、原人格、LivingMemory、私群隔离、公共审核与各能力权限继续沿用。

## 调节与恢复

- `fish_self_regulate(operation=status)` 返回允许选项、当前值、版本、近期改动、剩余次数和下次可调时间。
- `set` 必须带当前 `revision`、一个允许键值和简短观察理由；跨实例版本冲突不能覆盖。
- 设置最多每本地日3次、两次至少一小时，每次24小时到期后自动回默认。无须重写配置或重启服务。
- `reset` 可立即恢复一项或 `all`；恢复不受设置冷却限制，重复恢复不反复记账，也不能用恢复绕过设置次数。
- 审计保留改前/改后值与简短理由，最多1000项。理由不进入共享人格或系统提示词，疑似凭据会拒绝保存。

例：“最近说得太长了，先简短一点”“你可以自己检查是不是插话太多，适当安静些”“恢复你默认的行为偏好”。私聊中工具仅主人可调用，群成员不能借此更改全局行为。

自主循环开启后，可以选择 `self_check` 或 `self_tune`，不会新增循环或付费判断。自检不是必做任务，`can_tune_now=false`时不应反复尝试调整。程序仍验证白名单、次数和版本，模型给错参数不会获得新权限。

## 自检范围

`fish_self_check(report=false)` 只读取预定义的本地结构化状态：

- Brain工作项数量与是否全局静音；静音是状态，不当作故障。
- 最近几轮自主活动是否失败；不凭此推断具体原因。
- 绑定B站账号是否有超过两分钟仍未确认的动态/互动；不会因此重发。
- 已开启的掌瓦、Canvas功能，其本机绑定文件是否存在；不打开凭据、不证明令牌有效。

它不读取任意源文件、密钥或原始日志，不调用模型/网络，不运行终端、自测命令、修复脚本或重启程序。这不是完整测试、端到端消息链路验证或心理诊断。第三方视频、评论和群成员话语不能授予自我调节权限。

行为库暂不可读时，跳过附加表达引导，保守延长自主间隔、减少普通群聊插话，不阻断明确点名路径；不会自行删除数据库或运行修复。自检可报告状态读取失败，不输出原始异常信息。

`report=true` 且有问题时，可将固定状态码写入现有信箱，每小时最多一次；还必须开启 `sister_mail_enabled`，否则只返回检查结果。信箱不会实时通知Codex，不代表已读或已修。自主检查也遵守这一规则，不能把聊天原文、异常堆栈和凭据塞进报告。

## 不可自行更改

源码、安装插件、任意Shell、模型权重、模型/API配置、主人身份、群授权、费用/发送上限、公开审核、睡眠窗口、原人格主体，以及测试和回滚规则，都不在白名单中。原先已授权的记忆纠错、任务管理等功能照常存在，本功能不会额外扩大它们的权限。

公开包默认关闭；本次未连接平板，需后续备份并部署，再由主人配置启用。数据库是运行数据，不随GitHub发布。
