# 0.7.1：冷档回忆、夜间回顾与信箱连接

[English — 完整翻译](cold-memory.en.md)

本版在0.7.0基础上增加主人私聊文字冷存档、按线索回忆、可更正日记，以及电脑与平板的被动连接状态。不发布原设备的聊天、日记、信件、数据库、设备序列号或启动配置。参考设备的夜间任务已通过统一时间表改为香港时间每天 **05:00**。

## 1. 升级与启用

备份主插件、配置及私有数据，用本版主插件替换旧目录并在AstrBot中重载。它不要求重启在线NapCat。本版全部能力开关默认关闭，不把全关示例覆盖到现有配置。

先确保主人QQ、管理员、平台和 `bili_private_session` 都指向自己的当前私聊。后一个字段是已有能力共用的私聊目标，即使不用B站也需填写；完整UMO格式参见[从零教程](getting-started.md)。然后按需开启 `enabled`、`cold_archive_enabled`。夜间回顾还需 `timetable_enabled`、`memory_dream_enabled` 和实际可用的后台聊天提供商 `bili_provider_id`。不需要新建向量模型或把冷档导入Embedding库。

原有本地信箱继续由 `sister_mail_enabled` 控制。它与冷档开关独立；只想增加连接状态，不必先启用日记。

## 2. 信箱的连接、已读与回信

`fish_sister_mail(action="status")` 返回电脑连接状态与最近五封小鲸发信的状态；`read` 也附带这些信息。本机操作者可用 `python tools/sister_mail.py status`，先设置工具所需的 `ASTRBOT_ROOT` 为实际AstrBot目录。

| 状态 | 实际含义 |
| --- | --- |
| connected | 最近10分钟内收到电脑经既有ADB连接写来的心跳 |
| stale / unknown | 心跳过期或尚无可信记录；信仍保存在平板 |
| waiting | 信已保存，尚未确认已读 |
| read | Codex实际查看后明确执行了ack |
| replied | 有Codex署名、回复该信编号的本地回信 |

设备在线不等于主人可打扰，也不等于Codex正在运行、已经看到或即将回复。读取本身不偷偷设置已读，必须实际确认；没有自动通知、实时唤醒Codex或定时读信。提示词避免把断线描述成被忽略或要求主人一直连着。

## 3. 在电脑上设置心跳

`tools/computer_heartbeat.py` 是电脑运行的独立小程序，通过**已经授权且明确指定的ADB设备**向平板写时间戳。每60秒尝试一次、单次最多15秒；不监听端口、不自动连接新IP、不收集应用/游戏状态，也不读取聊天。断开时保留旧时间戳，平板约10分钟后判为过期。

先安装[Android官方Platform Tools](https://developer.android.com/tools/releases/platform-tools)，在本机确认 `adb devices -l` 中自己的平板已授权。ADB现有连接的设置与验证由部署者完成，不通过这个脚本绕过授权。

把 `examples/computer-heartbeat.example.json` 复制到仓库外，例如Windows的 `C:/FishPrivate/computer-heartbeat.json`，填自己ADB可执行文件的绝对路径和自己的设备序列号。不要提交实际配置。脚本的远端路径对应Termux中的 `~/AstrBot/data/plugin_data/astrbot_plugin_fish_capabilities/`；安装布局不同时先核对并调整脚本中的路径，不能只凭退出码认定机器人读到了状态。

在仓库目录先测试一次，再前台运行：

```powershell
python tools/computer_heartbeat.py --config C:/FishPrivate/computer-heartbeat.json --once
python tools/computer_heartbeat.py --config C:/FishPrivate/computer-heartbeat.json
```

在机器人主人私聊请求查看信箱状态，确认心跳年龄有更新。Windows长期运行可用自己的Python安装中的 `pythonw.exe` 替代 `python`，并在当前用户的启动文件夹为同一命令创建快捷方式；源脚本路径、配置路径和工作目录应为绝对路径。先手动验证，再设置登录启动。不需要管理员服务或持续显示终端。重复启动由配置旁锁文件限制为一个后台循环。

创建配置同名的 `.pause` 文件，例如 `C:/FishPrivate/computer-heartbeat.pause`，可暂停更新；删除该暂停文件恢复。去掉启动快捷方式可取消以后登录启动。程序在配置旁保存仅含时间、成功与否的 `.status.json`；不写凭据或聊天。

这是电脑经ADB连接平板的方案。电脑自己运行AstrBot时，不要把此脚本误装为本机通用心跳器；需要按实际主机路径适配，本版没有将该场景的夜间门控冒充实测兼容。

## 4. 冷档保存什么

仅捕获绑定主人私聊的文字，并按框架的会话覆盖、conversation、默认人格顺序解析当前人格。用户消息、模型生成文字和后台交给发送链路的文字分别标注来源；生成记录不代表QQ送达。语音只保存已有转写，不保存音频原件，图片不保存原件；不导入工具返回、隐藏推理、QQ登录目录或账号接口资料。

数据留在插件私有目录 `cold-memory/`。按香港日期分目录，原文以最多1200字分块、SHA256校验、只追加不覆盖；内容文件0400、索引0600、目录0700。索引用于显式关键词查询，不注册为普通向量记忆，也不每轮读取全文。已识别的Key、密码、Cookie和授权链接在落盘前过滤；自动过滤不能保证识别所有秘密格式，仍不要把凭据当普通聊天发送。

参考设备曾将当时数据库仍保留的24条聊天文字保存为25段。**没有恢复早已丢失的历史，也没有默认给其他部署者执行历史导入。** 缺逐条时间的旧记录标记 `import_snapshot`：目录日期是导入日，不代表当时说话日期；人格在导入时解析的记录也保留该限制。本版没有提供任意数据库一键导入工具，以免错误绑定会话和身份。

## 5. 按线索回忆与日记更正

主人私聊可以说“找找我以前提到某件事的原话”或“这条摘要好像和我当时说的不一样”。模型用 `fish_recall(operation="search", query="具体关键词", limit=2)` 找1～2段；每段最多1200字，查询至少间隔5分钟、同线索一小时不重复、香港每天最多12次。搜索本身不用云端Embedding；**返回的有限片段会进入当前云端模型请求**，并非绝不出本机。

`operation="diaries"` 最多查看三条私有日记。更正使用 `correct_diary`，需要实际ID、版本、最多600字完整新内容，以及主人当前消息中至少四字的明确更正原话；独立模型审查后保留审计、更新版本。不会修改原文冷档。

原文证明当时说过什么，当前明确更正与可靠实时结果优先。疑问、犹豫、玩笑不能变成确定事实，旧状态不能变成当前状态。日记是小鲸自己的带出处回顾，不是主人事实声明或原始思维链，不直接注入普通长期事实库，也不自动覆写现有摘要。第三方记忆插件仍应保持会话隔离和工具回合过滤。

## 6. 每天05:00的夜间回顾

首次启用时，统一时间表注册 `memory_dream`，默认cron为 `0 5 * * *`、时区Asia/Hong_Kong。参考平板原先03:30的已有任务已直接更新为05:00，没有新建重复任务。**升级不会强行覆盖已迁移任务**；旧预览版部署者应在主人私聊先列时间表，再修改已有夜间回顾，而不是重复创建。

只在香港03:00–08:00、电脑心跳有效、主人近30分钟没有实时聊天时运行。有消息则跳过，当前日没有旧材料也跳过。它只说明程序按夜间与安静条件执行，不判断人是否真的睡着。

每晚最多一次模型尝试，最多选择三段未用的旧片段，输出最多600字日记、模型输出上限500 Token。出处必须含实际片段ID和可逐字核对的短引用。超时、取消、格式无效或来源不符都不循环重试，重载也不清除当晚尝试记录。不唤醒电脑、不弹窗、不发QQ。可用 `fish_tasks` 暂停、修改、恢复或取消，修改后的时间仍受夜间门控约束。

## 7. 群聊与公开发送隔离

引用冷档或日记的私聊会话持久标记为私有上下文，B站起草不再引用该会话，相关QQ时间线也排除公开引用。该会话不能直接发表评论、楼中楼、动态或批准公开草稿；需要处理公开内容时换一个新的普通会话。日常后台公开视频阅读仍使用其独立资料路径。

群聊、非主人、非管理员均不能通过回忆工具访问冷档。后台公开模型没有该工具，日记也不注册进公共知识库。这些边界不取决于一句提示词要求模型保密。

## 8. 验证与回退

离线覆盖只追加、范围、默认人格、关键词转义、哈希、回忆预算、日记出处/更正/失败去重、连接状态及公开写入拦截。参考平板检查过框架真实事件、工具注册、私聊人格、旧文字归档和QQ/OneBot在线，并用虚构文字、模拟夜间时钟和真实模型跑通一次日记写入与引用核验。没有为发布公开发帖或向QQ发测试消息。

自然夜间调度、实际断开十分钟、Windows重新登录启动仍待正常使用观察。离线测试和一次模拟夜间成功不能替代这些验证。最新数量见[验证记录](validation.md)。

回退时先在时间表暂停夜间回顾，再关闭 `memory_dream_enabled` / `cold_archive_enabled` 并重载；不会删除已保存的冷档和日记。电脑心跳用暂停文件停止，取消登录启动另需移除自己创建的快捷方式。清理历史前自行备份，不能把私人备份提交Git。
