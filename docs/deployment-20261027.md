## 真机发现并修复

1. 原视频下载用过短的`Mozilla/5.0`请求头，CDN返回HTTP567。改为现有SDK的正常播放User-Agent及Referer，发送完整范围请求；200/206分别校验，206必须覆盖从0到完整总长度，不将部分响应当全文件。未向媒体CDN发送Cookie或账号凭据，未输出签名URL。
2. SDK偶尔返回不在允许范围的首选媒体地址，现在仅从SDK实际提供的安全HTTPS源/备用源中选取，不改写签名地址、不开放任意域名或端口。
3. 两次缓存记录时间戳相同会随机读到旧策略结果，补充rowid倒序；冻结时间回归已覆盖。
4. 逐页读取新增partial，增加必要的结构化输出空间；v6缓存隔离避免继续复用早期未读结果。

## HTTP412与日志

后续B站公开资料接口返回HTTP412，已停止反复探测，没有绕过验证、换IP或继续增加测试评论。之前的成功取流/扫描仍保留证据，但不能据此宣称之后的整个真实站点阅读链路全部复测通过。正常功能会在接口不可用时如实回报失败或保留可用预览。

测试期间有一次临时诊断插件卸载名称不匹配的ERROR记录，已按正确名称清理；不把历史ERROR数量包装为零。最终临时检查插件列表为空，能力插件仍激活。
