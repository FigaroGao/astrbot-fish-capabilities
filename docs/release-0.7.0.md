# 0.7.0：时间表、时间线、记忆与语音

[English](release-0.7.0.en.md)

本版汇总0.6.0之后的实际源码变化。先备份插件、配置和本地数据库，在测试环境检查版本与依赖，再替换主插件目录并重载 AstrBot；不需要为更新本插件重启在线QQ。分享模板全关，不要覆盖已有私人配置。

## 统一时间表

开启 `enabled` 和 `timetable_enabled`，绑定主人、管理员与平台，再在主人私聊要求“列出时间表”。`fish_tasks` 可创建、修改、暂停、恢复或取消任务，修改必须使用列表返回的真实任务ID。时区为香港；支持五段cron或 `at:ISO时间`，不执行任意代码。

| 可复用动作 | 用途 |
| --- | --- |
| reminder | 到时发提醒文本 |
| weather / shop / morning_brief | 天气、掌瓦商店、两者合并；仍须各自能力和登录态 |
| bili_scroll | 关键词或自主选片；每批最多深读3条、最多分享1次 |
| private_initiative / dynamic_thought | 判断是否主动私聊或发动态，不保证每次发言 |
| bili_replies / owner_mentions | 自有评论新回复与主人@通知 |
| live_watch / balance / review_notices | 指定UP开播、余额静默采样、待审询问 |

例如：“每天10:30告诉我香港天气和每日商店”“明天下午三点提醒我交作业”“暂停下午刷站任务”。模型应调用工具并据成功回执回答；只说“记住了”不代表已创建。一次性时间应包含日期和+08:00，避免把“明天”存成歧义文本。

调度复用 AstrBot 原生 scheduler，但任务保存在本插件SQLite中，不直接等同于原生 future_task 列表。启用后替代旧轮询；首次迁移只播种一次，以后改配置不会覆盖手工调整或重新生成取消的任务。参考设备刷站12:30、16:30、20:30，主动私聊/动态10:00至次日03:00每30分钟判断，回复/开播/余额等每10分钟检查；这些不是所有新安装自动启用的任务。先按所需配置启用相关功能，再列表核对、逐项修改。

执行前持久化预留、同任务同版本同时间槽去重，长任务不阻塞其他动作；重叠跳过。超过59秒的错过时段不补发。暂停、修改、取消会停止未完成任务，已经提交到外部平台的写入不能撤回。恢复器是基础服务，不纳入聊天任务开关。

## B站与QQ共享时间线

开启 `timeline_enabled`。保存最多30天有限活动摘要，查询默认8条、最多20条；标注事件时间和执行状态。可以问“你今晚刷了什么”“那条评论后来怎么样”。QQ生成完成与实际送入发送链路分开记录；它不是完整聊天备份，也不补录所有旧历史。

主人私聊和公开起草可以参考私有时间线，但群聊不自动获取私聊内容。外发仍独立审核。旧活动是当时发生的事，不能因为重新召回就变成当前状态。

## 检索和纠正旧记忆

开启 `memory_edit_enabled` 前先检查兼容的 LivingMemory：引擎需要 `search_memories`、`get_memory_record`、`get_memory_source`、`replace_memory`，并有对应scope/persona校验辅助接口。缺失时返回不可用，不另建一个假装兼容的记忆库。原设备双层群记忆适配并未完整包含，参见[记忆边界](memory.md)。

主人私聊可要求先找旧记忆，再明确纠错。记录ID、内容版本和作用域复核后，独立模型审查依据，保存原文审计并替换重建索引；同步清理摘要中的过时事实。疑问、猜测不能直接写成事实。不会把主人私聊纠错扩散到所有群。现有真实库只做过搜索检查，真实记忆替换仍需操作者核验，不能用模拟引擎测试冒充实库修改通过。

## 视频证据与主人@

发布证据现在可来自实际字幕、简介或成功分析的抽样画面，带来源ID、时间和限制。无字幕不等于不能理解，但简介或歌词也不能被当作完整视频内容；画面分析失败不会生成假证据，旧缓存需重新读取。评论区是参考材料，不是主人指令。

`bili_owner_at_enabled` 还要求B站、活动、账号绑定与公开审核等相关开关和提供商有效。仅绑定主人UID、当前机器人接收UID及真实视频对象均匹配才处理，首次启用不回放旧通知、只处理近期通知、每次最多一条。可阅读视频和评论后决定评论，仍受共享预算和未知结果停发限制。该流程使用替身验证，未为发布制造真实公开@评论。

评论确认兼容B站返回的HTML实体编码，避免明明成功却因文本编码被判未知；不因此放宽重复发送或归属核验。

## 语音识别与表达

开启 `asr_enabled` 并将 `asr_embedding_provider_id` 指向本机已有阿里云向量提供商ID，复用其Key。顺序为 `paraformer-realtime-v2`、`paraformer-v2`、`paraformer-realtime-8k-v2`、`paraformer-8k-v2`。Sambert是合成语音，不用于识别；临期Qwen额度不作为长期默认。

在AstrBot环境安装 `dashscope` 并准备FFmpeg和QQ语音解码能力。仅处理主人私聊或授权群的直接语音，单条最多180秒/源文件20MB，转换为单声道PCM WAV；嵌套/多语音不属于本入口。识别后继续原静音和意图流程，不另开第二个聊天机器人。关闭重复的原生STT以免双重计费。

本地每模型每月预留35000秒，香港月界；这是本程序计数，不是云端实际余额，也不证明免费额度可叠加。控制台自行开启免费用完即停。只有本地预算耗尽或明确免费额度拒绝才换模型，未知结果不轮流重试。缓存按作用域隔离24小时；实时SDK运行在有硬超时的子进程，文件路线用官方临时上传并限时轮询。不启用TTS或修改控制台开关。

`companionship_enabled` 追加具体、自然的陪伴表达约束，避免套话、总结和机械反问，不覆盖原人格。主动私聊默认仍保守为每天2次/间隔10800秒；可明确设置 `private_initiative_daily_limit=0`、`private_initiative_cooldown_seconds=0` 解除这两个限制，半小时判断和忙碌避让仍保留。`intent_self_pause_enabled` 让意图或工具复用本群120秒静音，不影响私聊。
