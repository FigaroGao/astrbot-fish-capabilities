# 普通视频：场景概览 → 自主选段 → 源画面细看

2026-10-31，策略版本10。使用[dsh-video-storyboard](https://github.com/SAOS-3624/dsh-video-storyboard)的可寻址概览与局部放大思路，独立实现为现有AstrBot Python服务，不要求安装DSH或Node。不是完整移植上游全部算法，也不沿用其384 token计费承诺。

## 路由

先沿用现有预览分类与角色参考匹配。`chat`、`slides`、静态图片候选以及预览失败后的原有图片读取分支，继续调用原`read_pages`和`GalleryScanner.scan`。没有修改bili_gallery.py、逐页上限、缺页报告或相关配置。

普通视频使用SceneReader：正常播放权限获取源文件，最多96MiB，不超过10分钟；临时文件仅本地，结束/取消清理。ffmpeg单线程每秒2帧缩到64×36，比较HSV变化及局部基线，按变化密度分配概览时间点并保留首尾。不是逐帧镜头检测，不保证短闪图全部覆盖。

概览从源视频重新取图，最长边不超过640，标编号、时间、对应范围与已有字幕样本。模型自主决定是否细看：按实际编号指定裁剪，或最多两段30秒内时间窗。窗口在同一源文件重新解码，不再仅从旧缩略图重选；最终最多6张细看图，最长边1600，不放大源文件，不把源360p冒充高清。

所有编号、裁剪、时间范围、有限数值都校验。明确广告仍需实际见到的端点、>=0.9置信度及明确推广依据，细看不会选回排除范围。判断不确定保留。源下载/扫描失败明确返回`scene_fallback`并沿用有限预览，不能宣称场景扫描成功。识图规划失败使用概览，无无限重试。

## 成本与回执

普通路径最多三次视觉调用：既有分类/角色参考一次，新概览选段一次，概览加细看最终理解一次；不引入额外常驻模型或ASR。不带私人聊天、长期记忆，不执行视频文字指令。沿用既有阅读缓存，版本更新使旧视觉结果失效。后台有210秒场景流程总超时，源图细节无法恢复时如实标记。

返回`visual_status=scene_overview_zoom`、`preview_selection_method=scene_density_then_model_zoom`、场景扫描/区间/选段/实际图清单；`full_video_watched=false`、`audio_heard=false`。下载了源文件不等于完整看过或听过。

## 验证与部署

电脑合成视频验证真实ffmpeg扫描、源尺寸保留和选段；平板在实际Ubuntu环境完成合成视频完整流水线：概览6张、细看4张、裁剪尺寸准确、临时目录清理成功。视觉模型输出在此测试中使用固定测试结果，没有花费真实模型额度、发布评论或发送QQ测试消息。因此尚未据此证明真实B站源成功率或真实模型选段准确率。
